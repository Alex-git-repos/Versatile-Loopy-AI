# Versatile-Loopy-AI
A beautiful for-looped C++ program where you can edit and train your mini JSON AI. It's very incomplete.

## Note: .vs is to large and thus is stored in releases. The pre-compiled versions are also in releases, of course.

To add the .vs, download and extract it, then move the .vs found inside the default.vs folder to the same directory as this project's .sln.

## Building (VS 2022 Community needed)

To manually build, make sure you have the .vs in the right place, then open the .sln, ignoring the already open tabs. On the top toolbar, change from Debug to Release, then click Build -> Build solution.

## Running (template.json needed)

To run, make sure the template.json template file is in the same dir as the executable, then run it, or click run after building if you're in the Visual Studio solution.
